# 项目理解与开发调研

## 项目目标与本次范围

提供的《项目申报表》将整体项目定义为“基于知识图谱与认知诊断的个性化学习路径动态生成系统”。其知识追踪模块需要读取学生作答序列、估计知识状态，并为后续情境融合和学习计划生成提供依据。申报书还提出遗忘建模和鸿蒙端侧适配，这些能力需要真实模型与设备实验支撑。

任务图片把鲁凯宁的当前工作细化为可独立运行的 Python 测试框架。验收要求明确允许训练组尚未提供模型时使用 Mock，运行 `python main.py` 输出统一 CSV。本次据此交付负责人 A 的全部工程成果，并约定负责人 B 能直接消费的预测格式。

现有目录只有申报表与四张任务图片，没有训练代码、模型权重、真实答题 CSV 或鸿蒙工程。因此本版本建立接入接口、人工测试夹具和可复现模拟数据；不把这些输入作为真实教育实验的证据。

## 因果预测与标签泄漏

DKT 论文把知识追踪表述为依据历史交互预测后续交互的表现。由此，本框架将目标题目的信息与答案分开：`Target` 不含当前 `correct` 或作答后才能获得的耗时，`history` 只包含同一学生之前已经可见的答案。当前标签只在推理完成后的 CSV 导出阶段关联。

相同时间戳或相同顺序号按同时发生处理，互相不可见。存在 `available_at` 时，早先开始但尚未完成的答题不能进入历史；同一个 `interaction_group` 中的答案也相互隔离。此处是基于数据可见性的工程约束，不等同于真实模型内部已完成因果遮罩审查。

来源：[Piech 等 Deep Knowledge Tracing 原论文](https://arxiv.org/abs/1506.05908)。

## ASSISTments 转换策略

官方数据页指出旧数据存在重复记录，修正版将同一次学生作答的多个技能合并成 `skill1_skill2`。转换器兼容这两种形式：按 `user_id + order_id` 合并重复技能行，同时要求题目、标签、时间与其他字段一致；不一致时终止并报告冲突。

原始答案是否正确直接来自 `correct`。缺失标签或技能不会被猜测。没有真实时间时，`order_id` 只用于先后排序，不能当作经过的秒数。采用 `start_time` 时，根据 `end_time` 或 `ms_first_response` 记录答案可见时点；无时区字符串要求接入方明确源时区。

来源：[ASSISTments 官方 Skill builder 数据说明](https://sites.google.com/site/assistmentsdata/home/2009-2010-assistment-data/skill-builder-data-2009-2010)。

## EdNet KT1 转换策略

EdNet 官方说明中，KT1 每位学生使用独立文件，日志的 `timestamp` 表示题目给出时间且单位为毫秒，`elapsed_time` 为答题耗时。题库提供 `correct_answer` 和分号分隔的 `tags`；KT1 问题还会按题组呈现。

本框架按 `question_id` 执行多对一关联，计算 `user_answer == correct_answer` 作为标签，保留每道题的多知识点，不将一题扩成多条评估记录。根据给题时间与耗时记录 `available_at`，并以 `solving_id` 隔离题组。缺少题库、未匹配题目、重复题库 ID 和非法答案都会失败，不以默认错误答案掩盖数据问题。

来源：[Riiid EdNet 官方数据仓库](https://github.com/riiid/ednet)。

## 技术选型

| 决策 | 理由 | 本版本处理 |
| --- | --- | --- |
| Python + pandas + NumPy | 与任务指定技术一致，便于读取表格与概率运算 | pandas 读取 CSV，NumPy 生成可复现数据和概率检查 |
| pytest + pytest-cov | 覆盖实际异常及可见性约束，便于保存机器可读证据 | 功能、接口、因果历史、转换器与 CLI 测试 |
| 不可变 dataclass 请求 | 明确区分目标信息和已知历史标签 | frozen Target / Interaction / PredictionRequest |
| 独立模型工厂 | 不强制训练组依赖某个深度学习框架 | `module:function` 接入，模型自行处理权重、设备与张量 |
| ID 对齐预测结果 | 批量推理可能乱序返回 | 验证数量、唯一 ID、有限概率后恢复请求顺序 |
| 固定知识点词表 | 训练与推理的编号必须相同 | 插件模式强制提供词表，未知知识点默认报错 |
| 明确时间单位与时区 | 避免纳秒/毫秒混淆及不同电脑的时区漂移 | ISO 时区字符串或显式 Unix s / ms |
| 原子写入与整体替换 | 失败运行不应留下看似成功的半份结果 | 临时目录生成全部文件，成功后替换输出目录 |

时间解析参考：[pandas 官方 to_datetime 文档](https://pandas.pydata.org/docs/reference/api/pandas.to_datetime.html)。

## 模拟模型的用途与边界

Mock 使用同知识点历史答案的 Beta(2,2) 平滑频率，冷启动概率为 0.5；没有随机推理、训练过程或遗忘机制。其结果随已知历史改变，可以检查序列是否真正传入模型。固定输入下，不同批量大小返回同样的结果。

真实模型精度、知识掌握度是否可解释、遗忘机制有效性、跨设备推理和鸿蒙端侧性能均需另行实验。当前输出的答对概率也不能未经模型定义就直接当作认知掌握度。
