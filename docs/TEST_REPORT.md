# 测试框架交付验收报告

验收日期为 2026 年 10 月 13 日，交付版本为 1.0.0。负责人 A 的七项工程任务已实现，自动测试及集成验收通过。以下实验使用合成数据与人工夹具，检查的是框架功能与接口契约，没有形成真实模型精度或遗忘机制效果的结论。

## 验证环境

macOS arm64，Python 3.12.14，pandas 3.0.6，NumPy 2.5.4，pytest 9.1.1，pytest-cov 7.1.0，ruff 0.17.0。完整锁定版本见 requirements-lock.txt。Windows 安装/运行脚本已提供，未在 Windows 实机执行。

## 自动测试

实际执行 `bash scripts/verify.sh`，**93 项通过，0 项失败，0 项跳过**。覆盖率为 **92%**，统计对象为数据读取、模型适配、Mock、主程序、流水线、数据转换、数据生成和输出工具；覆盖率不是正确性的完整证明。

| 检查范围 | 结果 |
| --- | --- |
| 空输入、表头缺失、重复列、破损 CSV | 明确失败，无成功输出 |
| 缺失标签/ID/技能、非法标签、负耗时、NaN/Infinity | 默认失败；drop 模式拒收并记录原因 |
| 前导零、字面 NA、多知识点去重、缺失可选耗时 | 按格式保留与规范化 |
| 学生分组、打乱数据、同一时点、历史窗口 | 排序稳定，同学生可见历史正确 |
| 当前/未来答案、其他学生答案、未完成答案、同题组答案 | 不进入不应可见的预测历史 |
| ISO 时区、Unix 秒/毫秒、缺少时间时的事件顺序 | 单位明确，顺序数据不伪造时间间隔 |
| 词表持久化、训练词表固定、未知技能 | 保留训练编号；默认拒绝未知标签，可明确启用 UNK |
| 模型工厂、推理异常、未接真实模型 | 明确错误，无自动 Mock 回退 |
| 预测数量、ID 重复/缺失/乱序、非法概率 | 严格验证，合法乱序结果按 ID 对齐 |
| batch_size 1 / 2 / 3 / 64 | Mock 的完整预测 CSV 相同 |
| CSV 标签对齐、输出 SHA256、失败保留旧结果 | 检查通过 |
| ASSISTments 多技能重复行与修正版格式 | 合并正确，冲突拒绝 |
| EdNet 题库关联与答题可见性 | 标签及多技能正确，未匹配题目失败 |
| CLI、不同工作目录、可复现数据生成 | 检查通过 |

静态检查 `ruff check .` 通过。机器可读证据在 qa/junit.xml、qa/coverage.json，完整日志在 qa/test_run.log。

## 集成验收

实际执行 `python scripts/acceptance.py`，**10 个命令检查全部通过**。其中 2 个场景预期返回退出码 2，用于确认异常行为，不能误计为成功推理。

| 场景 | 有效预测 | 拒收行 | 验收结果 |
| --- | ---: | ---: | --- |
| 默认模拟数据与 Mock | 288 | 0 | 12 位学生，6 个知识点，输出统一 CSV |
| 外部工厂模拟插件 | 288 | 0 | 工厂配置生效，乱序预测按 ID 对齐，仍标记 Mock |
| ASSISTments 人工夹具转换与推理 | 4 | 0 | 5 条源记录合并为 4 次作答，保留顺序，不生成时间间隔 |
| EdNet 人工夹具转换与推理 | 3 | 0 | 题库计算标签，同题组前两题均为冷启动 |
| 三条异常行的 drop 模式 | 285 | 3 | 其余记录运行，拒收清单含原始字段与原因 |
| 一万条模拟记录 | 10000 | 0 | 100 位模拟学生，全流程完成并核对输出数量和校验值 |
| 未实现的真实模型模板 | 无输出 | 不适用 | 退出码 2，明确提示尚未接入真实模型 |
| 三条异常行的默认严格模式 | 无输出 | 不适用 | 退出码 2，不发布成功目录 |

证据位于 evidence/acceptance.json 与 evidence/acceptance.log，每次成功运行均包含 CSV、词表、拒收清单与摘要。所有文件校验值在验收脚本中实际比对。

一万条模拟记录此次导出前流程耗时约 **0.232 秒**，其中模型调用约 **0.080 秒**，以该次 run_summary.json 为准；未计入 CSV 导出和进程启动。这是开发机上的模拟流程记录，不能作为真实 DKT/AKT、鸿蒙设备或生产吞吐的性能指标。

## 发布包验证

发布流程排除虚拟环境和缓存，把源码、锁定依赖、说明与验收证据放入 ZIP。包内 release_manifest.json 保存逐文件 SHA256，包旁提供 ZIP 校验文件。

候选发布包已解压到临时目录并新建独立虚拟环境，从开发机 uv 缓存安装锁定依赖。实际验证 `python main.py` 无参数运行成功并输出 288 条预测；发布包中的 93 项自动测试和静态检查再次通过。结果记录在 qa/release_smoke.json。ZIP 本身不包含依赖 wheel，其他机器安装依赖需要联网或自行准备包缓存。

## 未验证事项

尚未收到真实模型权重与真实数据文件，因此没有验证真实 DKT/AKT 数值结果、遗忘机制效果或正式数据集上的指标。EdNet/ASSISTments 转换仅用公开格式的人工夹具验收，没有处理全量真实数据。Windows 实机与鸿蒙真机未测试。真实模型须完成权重、词表、设备、编码与遮罩的接入审核后再进行正式评估。

## 复现

```bash
bash scripts/setup.sh
source .venv/bin/activate
bash scripts/verify.sh
python scripts/acceptance.py
python main.py --overwrite
```

可在不依赖训练组权重的情况下重现负责人 A 的验收目标。证据目录中的默认数据、其他示例和模型输出都标记其模拟用途。
